Chat is there for quick coordination before and during a battle. Keep messages game-focused, and never share passwords, payment information, account codes, or other private details.

## Party chat in the lobby

Join or create a party, then select **Chat** in the lobby. Party chat is visible only to the people currently in that party. It stays with the party—not a particular browser tab—so party members can pick up the conversation after reopening the lobby.

You can reply to a specific message, add a reaction, and see read status. A typing indicator only means someone is composing; it does not mean a message has been sent.

If you leave a party, you lose access to that party’s chat. Join or create a party again to use lobby chat.

## Chatting in a battle

Use **/** or the on-screen **Chat** control to open the battle composer. Choose **Team** for messages only your teammates can see, or **All Players** for everyone in the match.

Press **Enter** to send. Use **Shift + Enter** for a new line. Press **Escape** or close the composer when you are done so game controls return to normal. A match continues while chat is open, so use it when you can safely spare your attention.

## If a message does not send

First, check that you are connected and—when using lobby chat—still in the same party. If you have been sending messages or reactions quickly, pause briefly before trying again. Read [Chat rate limits and temporary restrictions](/help/chat-rate-limits) for what to expect.

If chat stays unavailable after reconnecting or waiting, [contact support](/help/contact) with your username, the approximate time, and whether the issue happened in the lobby or a battle. To report harassment or another safety concern, use the **Safety** category and include the player name and approximate time.
